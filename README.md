# 📚 Desafio Criativo - DIO
Este repositório contém minha solução para o **Desafio Criativo da DIO**, utilizando versionamento com Git/GitHub.  
O objetivo é criar um prompt claro e útil para orientar a Inteligência Artificial a gerar exatamente o que foi imaginado.
## 🧩 Etapas do Exercício
### 1. Intenção
Criar um prompt que ajude **alunos do 9º ano** a se prepararem para a **prova do IFSP** (Instituto Federal de São Paulo) para ingresso no ensino médio técnico.  
O foco é apoiar os estudantes com questões simuladas e um plano de estudo direcionado.
### 2. Contexto
- Público-alvo: estudantes do 9º ano.  
- Situação: preparação para exame seletivo do IFSP.  
- Entrada do aluno: escolha da **matéria desejada** (Matemática, Português, Ciências, História, Geografia).  
- Saída esperada: questões simuladas + plano de estudo estruturado.  
### 3. Restrições
- Linguagem acessível e prática, sem termos excessivamente técnicos.  
- Estrutura em listas claras e objetivas.  
- Conteúdo adaptável a diferentes realidades escolares e culturais.
